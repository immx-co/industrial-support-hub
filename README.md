Платформа управления инцидентами и автоматизации технической поддержки промышленных предприятий.

Система централизованно принимает и обрабатывает обращения сотрудников, связанные с промышленным и инженерным программным обеспечением.

Система должна сократить время обработки технических инцидентов за счёт:

- централизованного управления обращениями;
- распределения обращений между инженерами;
- контроля жизненного цикла обращения;
- разграничения доступа на основе ролей;
- асинхронной публикации событий через Apache Kafka;
- контроля сроков выполнения — SLA;
- автоматизации типовых диагностических операций;
- интеграции с внешними ERP- и PLM-системами.

Платформа должна обеспечивать полный жизненный цикл технического обращения:

1. Сотрудник создаёт обращение.
2. Диспетчер назначает инженера.
3. Инженер принимает обращение в работу.
4. Инженер устраняет проблему.
5. Сотрудник подтверждает решение.
6. Система сохраняет историю изменений и публикует интеграционные события.
7. В дальнейшем система будет контролировать SLA, отправлять уведомления и запускать автоматическую диагностику.

Собрать сервис: `docker compose --env-file .env --env-file version.env build support-service`

Запустить сервисы: `docker compose --env-file .env --env-file version.env up --no-build`
